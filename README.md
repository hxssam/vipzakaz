# ВИАЙПИ РЕСТОБАР — заказ продуктов

Лёгкое веб-приложение для оформления заказа на следующую поставку. Интерфейс и готовое сообщение для кухни — на русском языке.

## Возможности

- Каталог продуктов разбит на категории; поиск работает по названию.
- Нажмите «+» у товара: рядом появятся «−», поле количества, единица измерения и «+». Количество можно менять на месте или вводить вручную.
- Во вкладке «Другие товары» создавайте собственные группы и добавляйте товары в выбранную группу. Группы и собственные товары можно удалить; перед удалением группы приложение покажет, сколько товаров будет удалено.
- В каждой карточке собственного товара есть отдельная заметная кнопка «Удалить».
- Имя повара пустое при каждом запуске. Перед копированием нужно ввести имя вручную; если поле пустое, приложение показывает подсказку.
- Сообщение короткое: имя повара, время оформления, число позиций и товары по категориям с эмодзи. В сообщении нет нумерации и разделительных линий.
- Кнопка «Копировать заказ» сохраняет заказ в истории и копирует сообщение для вставки в чат кухни.
- Историю можно искать по повару, дате и названию товара; сохранённый заказ можно открыть, скопировать или удалить.
- Короткий звуковой сигнал подтверждает нажатие кнопок.
- Приложение не использует сторонние библиотеки и после первого открытия поддерживает работу без сети.

## Запуск на компьютере

Откройте терминал в этой папке и запустите локальный сервер:

```sh
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080` в браузере.

## Использование на телефоне

Чтобы открыть приложение на iPhone или Android и установить его на главный экран, разместите эту папку на веб-хостинге с HTTPS. Каталог и история хранятся в браузере устройства, поэтому автоматически между телефонами не синхронизируются.

Прямая отправка в группу не подключена: приложение формирует сообщение и копирует его, после чего его можно вставить в нужный чат.
